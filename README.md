# Pulse

Training and fuel planner for student athletes. Single-page app, no build step.

- Stepped onboarding that builds a 4-week periodised plan (Base, Build, Peak, Deload) matched to your equipment, sport and schedule
- Live session mode with set tracking, loads and session RPE
- Calorie, macro and water targets, food log and meal ideas filtered by diet and allergies
- Daily readiness check-in, training-load and body-weight charts

Data is stored in the browser (localStorage). Pulse gives general guidance, not medical advice.
